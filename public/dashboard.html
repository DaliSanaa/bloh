Welcome to Bloh

Generate your first API key below, then send a request to start extracting data from documents.

  1. Generate a key — click "Generate new key" in the API Keys section below.
  2. Copy the key — it is shown only once.
  3. Send a request — curl -X POST https://api.bloh.dev/extract -H "x-api-key: YOUR_KEY" -F "file=@document.pdf"
